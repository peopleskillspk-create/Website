# Image Shot List — People Skills Pakistan

Drop these into the `images/` folder using the **exact filenames** below. Each image slot already shows a finished brass-and-green panel with a caption, so the site looks complete before photos arrive — and each photo simply overlays its slot once added. If a filename is missing, the slot gracefully keeps the designed panel (no broken image).

## Sourcing
- **Free / licensed-free:** Unsplash, Pexels, Pixabay (check each licence).
- **Premium licensed:** iStock, Shutterstock, Adobe Stock (buy a standard web licence).
- **Best of all:** real photos from PSP's own sessions, faculty and clients (with consent).

## Style direction
Warm, professional, real Pakistani corporate settings — training rooms, boardrooms, frontline teams, Lahore/industry context. Avoid generic Western stock. Landscape 16:9 unless noted. Aim for natural light and authentic expressions.
